# 春知意步态验证 · 2.0.0-alpha.4

小米 13 的 alpha.3 录屏显示，春知意可以放在瓷砖地面上、走向不同目标并折返。约 16–18 秒切换方向时，两只鞋的轮廓在画面里重叠，脚下缺少明确的接触线索。录像用于本地分析。

春知意在 Unity 中交替抬脚转向。支撑脚的位置和朝向保存在放置锚点坐标系里。落脚后才生成花印，每只鞋的接触阴影在抬脚时减淡。点人物转向用户时也采用换脚动作。

## 可重复的编辑器检查

用 Unity 6000.3.29f1 打开 UnityProject，切换至 Android，执行 `SpringSample.ReviewAndBuildApk`，或执行 `SpringGaitReview.Run` 单独检查步态。运行时需要图形设备。测试以 30 Hz 模拟 255 帧，先直行 40 厘米，停步后原地转 180°，再往回走一小段。隔帧导出侧面图到 `reports/evidence/spring-gait-alpha4`。

共记录 33 次落脚，原地转身阶段有 8 次，支撑相内踝关节位移小于 0.1 毫米。花册检查也通过了两个隐藏角色分别收录，以及部分重置后的资格判断。

## 手机复测

从花册选择春知意，再点「来到现实」。在纹理清楚的地面上点两个相反方向的落点，观察换脚、脚底接触影和停步。新版真机观感待复测，桌面与地面验收分别记录。
