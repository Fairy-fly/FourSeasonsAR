# 春知意步态验证 · 2.0.0-alpha.3

小米 13 上使用 alpha.2 的体验者看到了花影放置、点地行走、长按拖动与轻点摊掌，并反馈走路时脚部动作不自然。这次修订集中在春知意的现实同行。

Blender 中按网格连通性区分两只鞋，分别校准错脚站姿下的髋、膝、踝。整只鞋随对应脚骨运动。现实中的支撑点保存在放置锚点坐标系中；移动距离驱动换步，膝盖向角色前方屈伸，落脚事件产生足迹。转向和启停带有速度过渡。

## 可重复的编辑器检查

使用 Unity 6000.3.29f1 打开 UnityProject。以 Android 为构建目标执行 `SpringSample.ReviewAndBuildApk`，或单独执行 `SpringGaitReview.Run`。步态检查需要图形设备。它加载 APK 使用的蒙皮资源，以 30 Hz 推进 165 帧，前 120 帧沿直线行走 40 厘米，随后停下，隔帧导出侧面图。输出在项目上一级的 `reports/evidence/spring-gait-alpha3`。

本次记录到 18 次落脚，支撑相内踝关节的最大位移在输出精度内为 0.00000 米。检查还覆盖摆脚抬升、停止后两脚收稳与足迹高度。发布页附 5.5 秒编辑器预览。

## 手机复测

在花册进入春知意详情，点「来到现实」。让她在纹理清晰的平面上朝侧面走一段，再点另一个方向，最后看她收步。重点观察支撑鞋是否滑动、后脚是否拖地、是否有膝盖反折。真人观感、桌边、追踪中断后的恢复分别记录。
