# 秋叶漫舞 · 2.0.0-alpha.5

秋叶漫舞的 3D 模型已接入扫卡和现实同行。Blender 工程保留 19 根骨骼及材质，移动模型约 6.4 万个三角面。脚底与底座分离，鞋与小腿交界处按原摆姿切开和封边。角色轻点时转身挥袖，裙摆随动作摆动，枫叶从手边旋落。

## 体验

1. 以 100% 打印秋季识别图，确认正方形图案宽 80 mm。也可以打开同一张图做屏显识别。
2. 点「开始扫描」，对准识别图。轻点角色收录进花册。
3. 打开秋叶漫舞详情，点「来到现实」。慢慢扫过地面或桌面，对准花影后点一下。轻点地面、人物或长按拖动，分别触发行走、回应或移动位置。
4. 春知意和秋叶漫舞都收录后，点右上角「下一位」，在同一落点切换角色。

识别图附在发布页，与 Unity 导入的参考图 SHA-256 一致。

## 验证

`SpringSample.ReviewAndBuildApk` 使用 Unity 6000.3.29f1 完成两位花灵的编辑器步态检查。秋叶漫舞的测试记录了 33 次落脚，其中 8 次发生在原地转身阶段。花册验证覆盖收录状态、角色详情和现实同行入口。秋叶漫舞的扫卡识别、现实放置及同位置切换待真机验证。

可编辑工程和 Unity 侧面回放可在发布页获取。使用原始花册 Blender 工程运行 `tools/blender/prepare_companion.py` 可重新导出骨骼网格。

## 挥袖修订 · alpha.6

小米 13 的 alpha.5 录屏中，挥袖时脸颊和下巴受手臂权重牵动。修订后，脸随头骨整体转动，袖口和裙摆按轮廓与贴图区分权重。轻点后短挥袖，枫叶从手侧放出。

`AutumnGestureReview.Run` 在 Unity 逐帧比较 5,514 个面部顶点相对头骨的位置，最大位移约 0.004 毫米。释放时手掌从静止位置移出约 19 毫米，低于脸部。检查输出为 `reports/evidence/autumn-gesture-alpha6`。新版真机观感待复测。
