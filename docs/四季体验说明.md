# 四时花旅 · 四季 Android 体验版 1.11

在支持 ARCore 的 Android 手机上安装同包的 `SeasonsFlowerJourney-FourSeasons-1.11.apk`。从 1.10 直接覆盖安装可保留已有花册进度。桌面图标为梅紫色底上的樱花与书页。打开封面右上角「四季花册」可以看收藏进度，首次扫描时需要允许使用相机。

1. 解压完整 ZIP，在电脑浏览器打开 `four-seasons.html`，点击角色名，一次显示一张卡。
2. 手机上点「开始扫描」，让完整方形图案占据约四分之一或更多的取景画面，缓慢移动手机。屏幕显示春知意、夏日花涧、秋叶漫舞或冬雪灵后，点人物后，花瓣会从两侧聚向屏幕下方的花笺，边框渐显后，名字和介绍也逐渐清晰。花笺完全展开后，再点人物可重看花瓣，文字会保持可读。
3. 首次识别角色后会看到「已收入花册」。点左上角返回封面，再打开「四季花册」。点已收集的卡位可查看立绘与花笺。再扫同一张卡，数量应保持不变。关闭应用并重新打开，花册应保留进度。
4. 打印时在页面选择角色，点「打印当前卡」，使用 100% 比例，量取整个方形图案的外缘应为 80 mm。手机对准实体卡后可继续验收平移、转动和遮挡恢复。

春卡继续使用 v2，另外三张使用各自的 v1 测试图。打印件和屏显件应保留完整边框。扫码时角色采用 2.5D 立绘。相机权限被拒绝时，在系统应用权限中允许相机，返回封面重试。

花册的四张常规卡各有一处画境。点亮后，点卡面可放大查看该角色的 2D 立绘、季节场景和花笺。目录下方的白金「时见」和紫色「星眠」各有独立预览入口。点击席位可以查看 2D 卡面和 3D 模型。预览不会写入收藏，也不会触发抽取。当前可扫码收集四位角色，进度分母为四。

在「四季花册」点已收集的「春知意」、「夏日花涧」、「秋叶漫舞」或「冬雪灵」，选择「查看 3D」。在画框内左右拖动可绕角色旋转一圈，上下拖动可稍微俯仰，双指分开或合拢可以缩放。点「查看 2D」回到立绘和花笺。再次打开 3D 时从正面开始。尚未收集时，先扫网页中对应的季节卡即可。

进入封面或花册时，可以看到墨色微粒从左向右聚成书名。两处题字与六位角色的名字采用龙藏手写体，花笺正文和操作文字采用霞鹜文楷。封面的聚字约 1.45 秒，花册约 1.18 秒，播放期间可以直接操作按钮。

时见与星眠分别采用白梅庭院和紫藤月湖。两款 2D 立绘均取自 1536 × 1536 的混元建模用正面原图。查看 3D 按钮采用玉绿或暮紫渐变，按下时有短促的金屑反馈。

收藏保存在本机应用数据里。1.3.1 没有保存扫码历史，升级后从第一次扫码开始收集。清除应用数据会重置进度。

## 从源码复现

用 Unity 6000.3.29f1 打开 UnityProject，安装对应 Android 支持模块；AR Foundation 与 ARCore XR Plugin 均锁定为 6.3.5。场景、四个角色预制体和识别图库均随源工程提供。运行 `.\tools\build-android.ps1 -Method SpringSample.BuildApk`。如需重新生成三个新增预制体和图库绑定，可先运行 `.\tools\build-android.ps1 -Method SpringSample.ConfigureSeasons`。

运行 `.\tools\build-android.ps1 -Method SpringPageReview.Render -WithGraphics` 可复测花册计数、详情和返回操作，并在 reports/evidence/ui-1.11-editor 下生成实际界面图。

检查冬雪灵时，可对比扫码花笺和花册详情里的“等晚归的人回房间”，两个页面的“回”字均应能看清内外两层。安装 Pillow 后运行 `python tools/check_return_glyph.py` 可复测正文字体在五个字号下的字形。

六款展示模型均有 Blender 工程，位于 derived/blender/hunyuan。Unity 工程已包含减面后的 FBX 及贴图。重建模型时，用 Blender 4.5.16 在后台执行 tools/blender/prepare_album_models.py，再用装有 Pillow 的 Python 执行 tools/blender/extract_album_maps.py。两个脚本从 assets/models/hunyuan 读取对应角色 ID 的原始 GLB。
