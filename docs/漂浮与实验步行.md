# 现实同行的移动方式 · 2.0.0-rc.4

封面左上角的「设置」可以选择现实同行的移动方式。初次安装或覆盖安装后默认使用漂浮。选择会自动保存，下次进入「来到现实」时生效。

- **漂浮**。六位花灵在地面或桌面上方几厘米轻轻起伏，移动时微微前倾，停下时回正。发束和裙摆随小幅摆动。脚下光晕固定在已识别的平面上。角色移动时会留下渐淡的季节印记。
- **步行**。设置中的小字标为「实验功能 · 测试阶段」。该模式使用已有的步行动作，冬雪灵的步态观感仍待改进。
- 两种模式均可轻点人物看招牌动作，点地面移动，长按拖动，双指旋转或缩放，以及在同一个落点换人。

## 验证

Unity 的 `HoverReview.Run` 模拟原地漂浮、移动、转向、停下和拖动，检查角色高度、回正及脚下光晕与平面的关系。`SpringPageReview.Render` 检查默认模式、实验标注、选项保存和文案字形。候选版在实际光线下的漂浮和光晕效果待真机复测。
