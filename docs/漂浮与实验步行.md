# 现实同行的移动方式 · 2.0.0-rc.9

封面底部的「设置」可以选择现实同行的移动方式。首次使用默认漂浮。覆盖安装会保留上一次的选择，修改会自动保存，下次进入「来到现实」时生效。

- **漂浮**。六位花灵在地面或桌面上方几厘米轻轻起伏，移动时微微前倾，停下时回正。发束和裙摆随小幅摆动。脚下光晕固定在已识别的平面上。角色移动时会留下渐淡的季节印记。
- **步行**。设置中的小字标为「实验功能 · 测试阶段」。该模式使用已有的步行动作，冬雪灵的步态观感仍待改进。
- 两种模式均可轻点人物看招牌动作，点地面移动，长按拖动，双指旋转或缩放，以及在同一个落点换人。

## 调整移动

每个数值两侧都有减号和加号。到达范围边界时，对应按钮会变灰。

| 设置 | 默认 | 范围与步进 |
| --- | --- | --- |
| 移动速度 | 100%（比 rc.4 快 28%） | 60% 至 150%，每次调整 10 个百分点。漂浮与实验步行都使用此值。 |
| 转向速度 | 165°/秒（rc.5 为 115°/秒） | 90 至 270°/秒，每次调整 15°/秒。用于自动朝向目标或用户。双指旋转直接跟随手势。 |
| 离地高度 | 35 毫米 | 25 至 70 毫米，每次调整 5 毫米。 |
| 起伏幅度 | ±9 毫米 | 0 至 15 毫米，每次调整 3 毫米。0 毫米时停在原处的花灵保持设定高度。 |

高度和起伏幅度只在漂浮时生效，表中数值对应角色放置后的原始大小。双指缩放时，高度与起伏等比例变化。

花灵在现实同行中移动或拖动时，会在身后留下对应角色的粒子。停下后粒子会在约一秒内散去。

## 外观样式

「设置 → 外观样式」可以分别为人物卡框和按钮选择「花笺」「圆角」或「折角」。选择立即生效并保存在本机。封面居中的「开始扫描」下方并排放置「设置」和「四季花册」。

花册沿用浅纸纹。四季卡配细角线和少量樱花、水纹、叶脉或雪晶。时见与星眠的卡片增加双线饰边，分别配时刻环与星轨。常驻特效沿卡面两侧移动，用较深轮廓和明亮内芯与淡色卡底区分。

## 花灵回应

轻点花灵后，等当前动作结束再点，她会在原动作和新动作之间轮换。连点会让当前动作继续播完。四季花灵可在扫卡和现实同行中触发，时见与星眠可从花册进入现实同行后触发。

| 花灵 | 新动作 |
| --- | --- |
| 春知意 | 侧身伸手接樱，翻掌送出花瓣弧线。 |
| 夏日花涧 | 提灯回望，另一只手随萤光抬起。 |
| 秋叶漫舞 | 回身舒袖，枫叶从腰侧旋出。 |
| 冬雪灵 | 低头吹雪，再把双手向外打开，雪花向前散去。 |
| 时见 | 转腕拨针，金粒在手边排成弧。 |
| 星眠 | 捧星抬眸，星光向上展开。 |

## 验证

Unity 的 `HoverReview.Run` 模拟六位花灵原地漂浮、移动、转向、停下和拖动，检查脚下光晕与粒子拖尾。`SpringPageReview.Render` 检查四项调节的上下限、封面入口布局、卡框和按钮独立选择与保存。真实环境下的转向观感和粒子效果待真机复测。

`CompanionActionReview.Run` 检查六位花灵在两套动作之间轮换、连点保护、手部轨迹、粒子释放和回到待机。秋叶漫舞的脸部变形检查覆盖两套动作。真机上的动作观感待复测。
