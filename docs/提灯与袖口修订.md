# 提灯与袖口修订 · 2.0.0-rc.11

夏日花涧的莲花灯原先与裙摆焊在同一张网格上。修订把粘连的接缝拆开并封边。灯体随持灯的手整体移动，旁边的布料随躯干和裙摆移动。

秋叶漫舞的袖口权重沿网格边缘逐步过渡到裙摆和躯干。两位的新动作都微调了抬手和转腕幅度，保留各自的表演节奏。

## 编辑器复测

Unity 的 `ClothRigReview.Run` 在两套实际动作中烘焙模型，比较提灯和袖口附近网格边的最大长度变化。表中数字是区域内各条边的峰值伸长比的第 98 百分位。1.0 表示边长维持原值。

| 区域 | 原动作修订前 → 后 | 新动作修订前 → 后 |
| --- | --- | --- |
| 夏日花涧提灯附近 | 2.64 → 1.10 | 7.30 → 1.27 |
| 秋叶漫舞袖口附近 | 5.62 → 2.05 | 5.57 → 1.86 |

秋叶漫舞的脸部权重另有回归检查。修订在真实摄像场景中的袖口和布料观感待真机复测。

在 Blender 4.5.16 中打开相应的原始绑定工程，后台执行 `tools/blender/refine_companion_cloth.py`，并在 `--` 后提供新目录，即可导出可编辑的 Blender 修订和 Unity 使用的 FBX。
