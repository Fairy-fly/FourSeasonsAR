# 《四时花旅》Android 2.0 真机验收

候选版在支持 ARCore 的 Android 手机上覆盖安装。打印时选实际大小或 100%，用尺确认方形识别图宽 80 mm。体验包中的 `cards/four-seasons.html` 也可以用于屏幕扫码。每条记录注明设备、应用版本，以及实体卡或屏显卡。

| 环节 | 操作与预期 | 候选版真机结果 |
| --- | --- | --- |
| 摄像头权限 | 初次允许后可打开扫码。拒绝后可退回，授权后再次进入可恢复。已有安装可在 Android 应用权限里切换相机授权，花册记录保留。 | 待测 |
| 四季扫码 | 分别对准卡片，绕到侧面。移动和转动实体卡时人物随动。遮挡后复扫，屏幕上只有一位。 | 待测 |
| 点击收录 | 点击空白和短暂丢失追踪时花册无变化，点击人物才收录。重复点击只触发动作。 | 待测 |
| 隐藏角色 | 四季齐后可分别点时见和星眠的立绘收录。部分重置其中一季时，已收录隐藏角色仍可召唤，未收录的等待四季重新集齐。 | 待测 |
| 地面放置 | 在有纹理的地板上点花影。点地面让花灵贴地漂浮，改方向时观察轻微前倾和回正，检查脚下光晕留在平面上。轻点看角色回应，人物出画后用「找回」。 | 待测 |
| 桌面边界 | 用「重新放置」切到桌面。向边缘点地面、拖动和缩放，花灵停在桌内。第二指落下时取消长按或移动指令。 | 待测 |
| 追踪恢复 | 短暂遮挡摄像头，切后台再返回。花灵先停住，定位恢复后重新检查落点。平面无法恢复时提示重新放置。 | 待测 |
| 实验步行 | 封面「设置」首次显示默认漂浮。切换到标注为「实验功能 · 测试阶段」的步行并重进现实同行，确认选择会保留。记录冬雪灵等角色的步态问题，再切回漂浮。 | 待测 |
| 移动调节 | 在设置里比较低速与高速、最低与最高离地高度、零起伏与最大起伏，以及自动转向的两个极限。每次调整后重进「来到现实」。确认达到上下限按钮变灰，实验步行可调整移动和转向速度。 | 待测 |
| 外观与拖尾 | 分别更换卡框和按钮样式，重新启动后检查选择。放置角色后点地面让她移动，再长按拖动，观察拖尾留在路径上并在停下后散去。 | 待测 |
| 六位轮换 | 放下已收录角色，点「下一位」，确认原地轮换仅显示一位。检查六位的招牌动作和特效。 | 待测 |
| 花灵的两套回应 | 扫四季卡或放置花灵。轻点后等她完成动作，再轻点观察新动作和对应粒子。快速连点时当前动作应播完。检查秋叶漫舞的脸部和冬雪灵的手脚。 | 待测 |

## 记录帧间隔

连上手机后，用 PowerShell 7 在仓库根目录执行以下命令，同时操作手机。使用 Unity 内置的 Android SDK 时，通过 `-Adb` 指定其中 `platform-tools/adb.exe` 的完整路径。

```powershell
.\tools\measure-ar-frames.ps1 -DurationSeconds 660
```

脚本保存应用自己的放置、换人、恢复事件和帧间隔统计。菜单、未放置、追踪暂停的时间不计入有效时长。若统计不足 600 秒，延长体验后再记一轮。输出位于 `reports/ar-frames-*.json` 和 `reports/ar-frames-*.log`。平均 FPS 由帧数除以有效时长，`worstWindowP95_ms` 是最慢一个窗口的第 95 百分位帧间隔。这些数值来自 Unity 主循环；现场同时记录可见卡顿和误触。

正式发布使用这张表与实际运行录屏。编辑器回放可对照角色和动作。
