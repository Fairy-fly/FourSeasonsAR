# 六位花灵现实同行 · 2.0.0-rc.1

已收录的花灵可从「四季花册」进入「来到现实」。对准有纹理的地面或桌面，点花影完成放置。点地面行走，轻点人物看招牌动作，长按拖动，双指调整大小和方向。收录两位以上时，点右上角「下一位」在原位置轮换。

| 花灵 | 招牌动作与特效 |
| --- | --- |
| 春知意 | 小步转身，伸掌散出樱瓣，落脚留下樱瓣花印 |
| 夏日花涧 | 提灯慢行，抬腕让灯光摇曳，落脚荡开水纹 |
| 秋叶漫舞 | 转身挥袖，枫叶从手侧旋落 |
| 冬雪灵 | 小步轻走，捧手聚拢雪晶，雪痕慢慢淡去 |
| 时见 | 行礼后停腕，金砂先停驻再落下 |
| 星眠 | 回眸伸手，指尖亮起一段星轨 |

春、夏、秋、冬使用同版识别图进入扫卡相遇。收集四季后，去花册点时见、星眠各自的立绘收录。已收录的隐藏角色可单独加入现实同行，也可参与原地轮换。

## 验证

- Unity 6000.3.29f1 以 Android 为目标执行 `SpringSample.ReviewAndBuildApk`。六位均通过了直行、原地换脚转向、折返、停稳、招牌动作和足印高度检查。
- 花册检查覆盖收录持久化、隐藏角色的独立资格、部分重置、六位的轮换顺序和现实同行入口。秋叶漫舞的脸部权重回归检查通过。
- 春知意转身换脚与脚下阴影、秋叶漫舞挥袖修订已有小米 13 的体验反馈。候选版的六人真机扫卡、两位隐藏角色放置、场景轮换、桌面边界和十分钟帧率仍待实测。

可编辑 Blender 工程在候选发布附件里。各角色独立建骨，模型从同版花册雕刻网格导出。脚底校准值与步幅保存在 `CompanionProfile`。
